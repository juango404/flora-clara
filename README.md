# Flora Clara

Landing page estatica para una floristeria con quiz de recomendacion por emocion.

## Vista rapida

Abre `index.html` o publica el repositorio con GitHub Pages desde la rama `main`.

## Personalizacion

- Cambia el numero de WhatsApp `573001112233` por el numero real del cliente.
- Ajusta precios, nombres de ramos e imagenes en `script.js` y `index.html`.
